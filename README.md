# Upbit RSI 감시 프로그램

업비트 거래소의 KRW 마켓 상위 30개 코인에 대해 RSI(상대 강도 지수)를 계산하여 **RSI 값이 30 미만인 경우 텔레그램으로 알림을 전송**하는 프로그램입니다. 이 프로그램은 5분봉 기준으로 작동하며, 다음 5분 단위 시간이 시작될 때 데이터를 동기화하여 정확한 알림을 제공합니다.

---

## 주요 기능
1. **RSI 감시 및 알림**:
   - 거래대금 기준 상위 30개의 KRW 코인을 대상으로 RSI 값 계산.
   - RSI 값이 30 미만인 경우 텔레그램 알림 전송.
2. **5분 단위 동기화**:
   - 프로그램은 5분 단위로 동작하며, 최신 데이터를 기준으로 RSI를 계산.
3. **프로그램 시작 및 종료 알림**:
   - 프로그램 시작 시 텔레그램으로 알림 전송: `🔵 프로그램 시작: 업비트 5분봉 RSI 감시 시작`.
   - 프로그램 종료 시 텔레그램으로 알림 전송: `🔴 프로그램 종료: 데이터 감시 종료`.
   - 프로그램 작동 시 알람 예시: 🟢 BTC / 5분봉 / 10:20기준 / RSI : 29.23
